## 2. Surgical General-Capability Gap Matrix (`G1`–`G10`)

Every item below is verified against `agent-jack-3` `origin/master` (`e898f38d1`) and scoped as a **general Agent Jack platform improvement** (never test-specific hardcoded logic).

| ID | Area | Priority | Exact File Path(s) & Verified Current Behavior | Proposed Surgical General Jack Improvement |
|---|---|---|---|---|
| **G1** | **Webapps — Console & Network Observation** | **P0** | `api/src/jack_api/agent_mcp.py:621, 8563-8574`: `browser.console` and `browser.network` are permanently stubbed to return `_browser_unavailable("Computer does not expose console or network observations")`. | Expose bounded console (`{level, text, sourceUrl, line}`) and network (`{method, url, status, resourceType, durationMs}`, redacting `Authorization`/`Cookie`) observations from the Computer browser driver via CDP/Playwright so `browser.console` and `browser.network` return live structured data. |
| **G2** | **Webapps — Semantic DOM/ARIA, Viewport, Theme, Locale & Cookie Ergonomics** | **P0** | `api/src/jack_api/blaxel_computer.py:600-835`, `agent_mcp.py:8480-8560`: Cloud Computer browser relies on X11 `wmctrl` window titles + raw `(x, y)` coordinate clicks and fixed desktop resolution. No ARIA/DOM snapshot, no selector/ref targeting, no viewport resize (`360`/`390`/`1280`), no `prefers-color-scheme` (`light`/`dark`), no locale (`Accept-Language`), and no cookie/storage-state inspection or isolated profile toggle. (Even `api/src/jack_api/builtin_skills/gstack/BUNDLE.json` holds `gstack-qa`, `gstack-browse`, `gstack-design-review`, and `gstack-setup-browser-cookies` for this exact reason.) | Implement a Playwright/CDP-backed `BrowserComputer` driver behind the existing `BrowserComputer` protocol (`agent_mcp.py:878`) adding general tools/options: `browser.snapshot` (ARIA tree + element bounding boxes + overflow metrics), `browser.set_viewport(width, height, color_scheme, locale)`, `browser.cookies` (redacted metadata: name, domain, `HttpOnly`/`Secure`/`SameSite`), and optional selector/ref targeting on `browser.click` / `browser.type`. |
| **G3** | **Webapps — Vision Screenshot Delivery & Persistence** | **P1** | `api/src/jack_api/agent_mcp.py:624, 845-864`: `browser.screenshot` caps base64 PNG at `MAX_BROWSER_IMAGE_CHARS = 350_000` (~260 KB) and sets `imageOmitted: true` whenever exceeded (frequent on real 1280px pages!), returning only `imageSha256` with no persisted file or MCP `ImageContent`. | Persist full-res PNGs from `browser.screenshot` into the turn's `outputs/` / `TalkMediaStore` (returning `mediaRef` + `sha256`) and emit a bounded WebP/downscaled MCP `ImageContent` so vision-capable models can reliably inspect screenshots without silent omission. |
| **G4** | **Webapps — Seat-Allowlisted Staging Origins** | **P1** | `api/src/jack_api/browser_url_policy.py:49-125`, `guest_egress_proxy.py:55-95`: `browser.navigate` and `web.fetch` block all private/loopback/CGNAT/non-443 hosts and require `public_navigation`. Cloud Bots cannot inspect seat-owned private/staging hosts or custom HTTPS ports. | Add an explicit seat-admin-configured **exact host+port egress allowlist** (no wildcard private CIDRs; RFC1918/metadata/link-local remain blocked by default) for Business/Operator seats. |
| **G5** | **API / CLI / DB Probes — HTTP Contract Metadata & Sandbox Output** | **P1** | `api/src/jack_api/web_lookup.py:114-142`, `agent_mcp.py:8066-8090`: `web.fetch` is public `GET`-only, truncates body to 2,000 chars, drops redirects (`follow_redirects=False` returns `None`), and omits status code, response headers, and latency. `api/src/jack_api/fly_sandbox_runtime.py` (`sandbox_run`) returns `exit_code` and `cost_line`, not bounded `stdout`/`stderr` or generated files. | Add a general bounded `http.probe` (read-only `GET`/`HEAD`/`OPTIONS` returning status, latency, redacted headers, redirect chain, bounded body; approval-gated writes only on allowlisted staging hosts) AND return bounded `stdout`/`stderr` tail + promoted `outputs/` artifacts from `sandbox_run`. |
| **G6** | **Desktop & Mobile Native Apps — Paired Mac Device Bridge** | **P0** | `desktop/src/device-bridge-executor.mjs:276-306`, `api/src/jack_api/agent_mcp.py:7302-7325`: `machines.dispatch` supports only 4 hardcoded verbs (`desktop.write_text`, `desktop.list`, `desktop.cleanup_sorted`, `chrome.open`). Server-hosted Bots cannot launch/inspect macOS native apps, capture window screenshots, inspect Accessibility trees, or drive iOS Simulator; native checks currently require routing the entire Bot turn to a Paired Mac via Tentacles. | Add consent-gated Paired Mac Device Bridge verbs (opt-in per machine in Desktop Settings): `app.status` / `app.launch` (user-allowlisted bundle IDs), `window.screenshot` (Screen Recording permission -> `TalkMediaStore`), `window.ax_tree` (Accessibility permission -> bounded JSON tree for macOS/Electron/Simulator windows), and bounded `simctl` read/screenshot profiles. |
| **G7** | **Evidence & Reporting — Approval-Gated `linear.file_issue` MCP Tool** | **P1** | `api/src/jack_api/agent_mcp.py:8970-8972`, `linear_runtime.py:143-179`, `talk_http.py:5629`: Native `agent_mcp.py` exposes only `linear.issues` (read), `linear.comment` (estate-line scoped comment), and `evidence.append` (comment). `TalkLinearRuntime.file_issue()` exists on HTTP (`POST /api/talk/v1/linear/issues`) but is NOT exposed as an MCP tool. OAuth Linear MCP (`mcp_providers.py:51`) can create issues if connected, but bypasses Jack's native `LinearCard` ledger and durable human-approval gate. | Expose `linear.file_issue` in `agent_mcp.py` backed by existing `TalkLinearRuntime.file_issue()`, gated by `human_gates.py` (or explicit seat `approval_rule_store.py` opt-in), supporting optional labels, priority, parent issue, and Talk artifact links. |
| **G8** | **Routines — Controlled Opt-In for Browser/Tentacles on Scheduled Runs** | **P1** | `api/src/jack_api/agent_mcp.py:584-596`: `ROUTINE_BORROWS_ACCESS` blocks every routine from borrowing `browser.use` or `tentacles.hire`. Scheduled and release-webhook verification routines cannot execute browser or Paired Mac checks. | Add an explicit per-routine owner opt-in (`allow_abilities: ["browser.use"]`) with bounded timeout/cost ceiling and mandatory owner confirmation on create/edit so post-release or nightly verification routines run safely without silent privilege borrowing. |
| **G9** | **Packaging — `jack.team` v2 Bundled Skills & Review-Gated Capabilities** | **P1** | `api/src/jack_api/team_package.py:29, 108-220`: `TeamPackageV1` (`extra="forbid"`) has no `skills` or `requested_capabilities` fields on `MemberV1`, and `HatV1.tools` admits only `POLICY_TOOLS = {"talk.read"}` (marking all other tools as `denied-tools:`). Meanwhile `TemplateShareSnapshotV1` (`schemas/v1/template_share.py:86-135`) supports `skills`, `skill_definitions`, `plugins`, and `capabilities`, but only for single-Bot share links, not portable local `jack.team` packages. | Add backwards-compatible `jack.team` `version: 2` supporting optional `skills` / `skill_definitions` (32 KB cap), `requested_capabilities` (surfaced in Preview with explicit owner consent checkboxes — never auto-granted), and non-secret `webmcp_servers` hints. |
| **G10** | **Evidence Packs — Direct Artifact Attach Tool** | **P2** | `api/src/jack_api/talk_artifacts.py:67-68`: Attachment promotion relies on scraping host `outputs/` paths from assistant text and caps replies at `TURN_ARTIFACT_LIMIT = 5`. | Keep `TURN_ARTIFACT_LIMIT = 5` (skills bundle screenshots/logs into 1 ZIP + `MATRIX.md` + `verdict.json` + up to 2 inline PNGs), and add a general `artifact.attach` MCP tool so Bots on any engine (including Paired Mac / Fly Sandbox) can promote bounded files to `TalkMediaStore` without host-path text scraping. |
