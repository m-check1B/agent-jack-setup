# REPAIR: one fix per FAIL code

**macOS:** the Agent Jack doctor (`/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/m-check1B/onboarding/main/agent-jack/doctor.sh)"`) prints, for every FAIL or WARN, one plain sentence and exactly one next step; follow that line, then run the doctor again. Never stop at the first FAIL. The table below holds only the codes both systems share (sign-in, reply, sandbox, browser, T3 updates); every other macOS code is explained by the doctor's own report line.

**Windows:** run `powershell -NoProfile -ExecutionPolicy Bypass -File bin/doctor.ps1`, find the code, apply the fix (ask the person before any change), then verify with the doctor. A row in [Windows](#windows) replaces the shared row with the same code; codes without a Windows row (sign-in, reply, sandbox, pairing, Local Bot, browser) are fixed the same way. If a code is missing here, or the fix doesn't work: put that FAIL in the report and carry on with every step that does not need it. This file grows from real cases, and every new real problem gets a code.

## Windows

Windows 11, Windows PowerShell 5.1. Every script runs as `powershell -NoProfile -ExecutionPolicy Bypass -File bin/<script>.ps1 …` (that one process only; forward slashes work in PowerShell and in Claude Code's Git Bash).

**Refresh PATH**: the AI app's shell keeps the PATH it started with, and every command the agent runs is a new process, so this line run on its own changes nothing. After each winget install, put it at the start of **the same command** that needs the new tool, e.g. `<line>; node -v` or `<line>; git clone …`. From Git Bash (Claude Code), put the line and the check inside **one** `powershell -NoProfile -Command "…"`. Fallback: the person restarts the Codex / Claude app. `bin/doctor.ps1` and `bin/install.ps1` run it themselves, so verify with the doctor:
`$env:Path = (($env:Path, [Environment]::GetEnvironmentVariable('Path', 'Machine'), [Environment]::GetEnvironmentVariable('Path', 'User')) -join ';' -split ';' | Where-Object { $_ } | Select-Object -Unique) -join ';'`

**WAIT** lines are not failures. Today a Local Bot on Windows waits for a Windows proof of T3 Code (Beta); the Bot runs on our server (gear → Engine → a **Server · …** lab, or Classifier). AJ-PIN-00, AJ-TENT-03 and AJ-LOCAL-00 show WAIT until then: record them in the report, don't repair them. Never `Set-ExecutionPolicy`, never disable Defender, SmartScreen, UAC or the firewall. A UAC window is always confirmed by the person, never by you.
