# macOS: use the Agent Jack doctor

This prompt is retired. On a Mac, one command installs, repairs and checks everything (the Agent Jack app, the official T3 Code (Beta), Tentacles, Codex CLI, Claude Code CLI):

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/m-check1B/onboarding/main/agent-jack/doctor.sh)"
```

With Codex or Claude Code, give your agent the guide https://github.com/m-check1B/onboarding/blob/main/agent-jack/AGENTS.md: it asks you once, runs the same command and shows you the report.
